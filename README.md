# miba-workjournal-public

Публичный канал раздачи обновлений приложения MIBA.VIDEO WorkJournal.

Здесь лежат только скомпилированные APK-файлы и списки изменений (GitHub Releases).
Никаких личных данных сотрудников здесь нет — они хранятся в отдельном приватном репозитории.

Приложение само проверяет вкладку Releases и предлагает обновление, если доступна более новая версия.
